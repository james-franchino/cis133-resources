# HTML and CSS Resources

## HTML: HTML Dog

[HTML Dog - HTML Beginner Tutorial](https://www.htmldog.com/guides/html/beginner/)

HTML Dog breaks HTML into short, step-by-step lessons covering elements such as headings, links, images, and forms. I think it is useful because it explains how to structure content and finishes by combining the concepts into a complete example.

## CSS: Flexbox Froggy

[Flexbox Froggy](https://flexboxfroggy.com/)

Flexbox Froggy is an interactive game that teaches CSS Flexbox by having you position frogs on lily pads. I think it is useful because you can see how changing CSS properties affects the layout immediately, which makes the concepts easier to understand.
